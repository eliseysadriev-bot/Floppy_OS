# Floppy 1.0

Любительская операционная система, написанная на ассемблере NASM.

Всю систему создали с помощью искусственного интеллекта. Автор придумывает идеи и тестирует её, а большую часть кода пишет ИИ.

## О системе
- 32-битное ядро защищённого режима с собственным 16-битным загрузчиком
- Графика 800x600, 16 цветов, собственные драйверы мыши и клавиатуры
- Чёрный, белый, серый и синий цвета с резкими тенями
- Рабочий стол с окнами, которые можно перетаскивать и менять им размер, и с часами
- Окна About и Settings
- Курсоры мыши: стрелка, рука, текст, изменение размера, а также курсор «занято» с экраном загрузки

## Программы
- FloText: текстовый редактор с выделением мышью, копированием, вырезанием и вставкой
- FloPaint: программа для рисования с инструментами, ползунком размера кисти, палитрой, отменой и заливкой
- FloFile: файловый менеджер с папками, переименованием, удалением и списком дисков
- FloCalc: калькулятор
- Boil: небольшая игра, в которой нужно остановить микроволновку в нужное время; результат сохраняется в файле
- Окна Open и Save, общие для всех программ

## Система
- Собственная файловая система с папками
- Три диска: C, O и I; пустой диск форматируется автоматически
- Системная папка flopsys на диске C с программами и играми
- Программы это отдельные модули .sys, которые загружает загрузчик
- Полосы прокрутки и ползунки везде, где содержимое не помещается

## Как запустить
Нужны NASM и QEMU (или Bochs 3.1).
- Windows: запустите build.bat для QEMU или run_bochs.bat для Bochs
- Linux и macOS: запустите build.sh

## Статус
Ранняя экспериментальная версия, возможны ошибки. Сделано для удовольствия и для обучения ассемблеру.
