FIX 1 — Disks / Size input
- Implemented full text editing behavior required by "ПРАВИЛА НА ВСЕГДА" in zametki.txt:
  * I-beam mouse pointer over the Size input (already routed by the previous patch).
  * Clicking places the caret at the nearest digit boundary.
  * Dragging with the left mouse button selects a digit range.
  * The selection is visibly highlighted, and the caret tracks the click.
  * Backspace removes the previous digit or the selected range.
  * Delete removes the next digit or the selected range.
  * Ctrl+A selects the complete Size input.
  * Ctrl+C copies the selected digits to the shared clipboard.
  * Ctrl+X cuts the selected digits.
  * Ctrl+V inserts digits from the shared clipboard at the caret, replacing selection.
  * Left/Right/Home/End navigate within the Size field.
- Only ASCII digits 0..9 can be entered; invalid characters from paste are ignored.
- Maximum five digits, minimum/maximum sector constraints unchanged (180 KiB..32 MiB).
- Existing Name field now also recognizes the Delete key without changing its other behavior.
- No additional size presets, applications or file-system features were introduced.

FIX 2 — Desktop EN/RU toggle
- src/desktop/minimize.asm:mn_arrow now temporarily uses zero cw_x/cw_y
  while drawing its absolute-position language toggle, then restores the prior
  window origin. This avoids the Main window offset corrupting the toggle.
- Existing screen coordinates, shadow and labels are unchanged.
